# License setup before first public release

The current POM is configured for Apache License 2.0 metadata as a placeholder for the public release configuration.

Before publishing the first release, confirm that Apache-2.0 is the intended project license and add the corresponding `LICENSE` file to the repository. If another license is chosen, update both the POM metadata and this documentation before publishing.

Do not publish the first Maven Central release until the license decision is finalized.
